Projeto Aula_CNW - Jogo Web Responsivo
=======================================

Ficheiros organizados na raiz:
- index.html: Estrutura HTML do site com suporte a controlo mobile.
- style.css: Estilização do jogo e dos botões virtuais para telemóvel.
- script.js: Lógica do jogo e captura de eventos de toque/teclado.
