# Aula CNW - Jogo Arcade Web

Jogo web responsivo com controles na tela para celular e suporte a teclado.

## Arquivos

- `index.html`: estrutura da página e botões virtuais.
- `style.css`: visual do jogo e dos botões.
- `script.js`: captura de teclado e toque (os botões da tela simulam as teclas).

## Como rodar

Abra o `index.html` no navegador.

## Publicar no GitHub Pages

1. Envie os arquivos para a raiz do repositório (o `index.html` precisa ficar na raiz).
2. No repositório: **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde 1–2 minutos. O link aparece na mesma tela.
