# Aula CNW - Jogo Arcade Web

Jogo web responsivo com controles na tela para celular e suporte a teclado.

## Arquivos

- `index.html`: estrutura da página e botões virtuais.
- `style.css`: visual do jogo e dos botões.
- `script.js`: captura de teclado e toque (os botões da tela simulam as teclas).
- `online.css`: visual do sistema de rank dos jogadores.
- `online.js`: estrutura lógica da pagina de rank de usuários.

## Como rodar

Abra o link `https://gustavofrazatto1-svg.github.io/Aula_CNW/` no navegador.
